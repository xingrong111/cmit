# 成员4独立网页端

新增日期：2026-10-11。界面参考成员2人物阅读版的色彩、字型、留白与导航结构，未合并成员2代码或业务数据。

## 入口与运行

- 当前运行的网页端：`http://127.0.0.1:3104/web/`。
- 网页分入口：`/web/#assistant`、`/web/#radar`、`/web/#route`。
- 原小程序风格预览仍在原地址 `http://127.0.0.1:3100/`；原生小程序代码仍在 `AIassistance/miniprogram`。
- 后端服务重新启动后也可在其端口访问 `/web/`。当前3100的旧进程尚未重启，所以先使用3104查看新版本。

PowerShell从 `E:/CMIT/AIassistance/server` 运行：

```powershell
$env:PORT='3104'
node --dns-result-order=ipv4first --env-file-if-exists=.env src/server.js
```

`.env` 继续只在服务端保存。预览静态页面目前依照原项目规则只在 `PUBLIC_MODE=false` 开放；正式部署时应单独设计前端托管和发布资料准入，不能直接为了打开页面关闭资料保护。

## 实现方式

网页端文件独立放在web目录。index.html载入原有preview组件样式、live-map.js及app.js，然后由web/app.js重新组织网页布局、导航和页面状态。对话、地点、来源与路线继续调用同一套Node接口；web没有复制一份后端或一份人物数据库。

原preview页面、样式、脚本和原生miniprogram均未改动；server.js仅增加web静态文件白名单。这样后续修复共享对话或地图逻辑时，网页端也能复用。若以后改动原preview的DOM选择器或函数名称，需同时检查web布局适配器。

小迹页：场景/偏好侧栏＋独立对话区域，保留停止回答、编辑提问、复制回答、重试、出处与地点卡操作。

足迹页：城市/类型筛选＋地图与地点双栏，支持地图/列表切换、地点详情、加入路线。未配置专用浏览器地图Key时明确显示主题示意图，不伪装真实地图；不能将服务端腾讯Key传入浏览器。

路线页：地图和时间预算＋站点编排双栏，保留最多4站、上移、移除、停留时间、本机保存、清空和复制计划。真实步行计算仍以已核入口及地图服务条件为准。

地点详情：资料卡双栏，保留开放与核验说明、官方来源、关联人物、问小迹和加入路线。
