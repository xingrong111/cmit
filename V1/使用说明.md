## 目录

- frontend：以成员2为基础的uni-app源码；统一导航、阅读和评论入口，网页通过同源模块容器接入账户/导览。已编译H5与小程序。
- services/reading：成员2只读Node/Express/SQLite资料服务。
- services/account：成员3账户、评论及审核后端/前端；含V1必要修复及原生页。
- services/guide：成员4地图、路线、小迹及原生页；私有运行配置仅在server/.env，不应分享。
- 微信开发者工具导入包：组装后真正包含三成员页面的单一微信工程。请导入这一目录，不能只导入frontend/dist/build/mp-weixin中的中间产物。
- tools/组装小程序.py：每次重新编译小程序之后运行此脚本组装原生页、配置和App桥接。
- docs：接口验证、浏览器截图、ID映射、问题与范围说明。

## 重新构建

frontend目录执行 `npm ci`（当前已备依赖）、`npm run build:h5`、`npm run build:mp-weixin`。然后V1目录执行 `python tools/组装小程序.py`。阅读后端缺依赖时在services/reading执行npm ci。

H5默认同源/api/reading；微信开发前默认本机3110，真机必须换成手机可访问的HTTPS域名。正式构建需设置VITE_API_BASE，并同时修改组装脚本输出的config.js（导览）及utils/account-api.js（账户）对应地址；不得把AppSecret或模型密钥写入微信包。开发者工具本机预览时临时关闭合法域名校验；正式上线须配置真实AppID与合法域名。

导览DeepSeek/Tencent配置沿用现有私有server/.env。此文件及任何备份不要发给队友或打包上传；按权限单独配置。服务器端Key未写进前端；专用浏览器地图Key按既有机制公开。
