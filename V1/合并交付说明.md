# 山河有迹 · 五部分合并版

本次已将全国地图与名单、人物档案与长卷、账户评论审核、小迹导览与历史足迹、学习挑战整合到 V1。原成员目录保留。

## 两端文件

- `网页端/页面`：已构建的网页页面，需通过统一服务访问。
- `网页端/源码`：统一 uni-app 源码；`模块页面`保存账户、导览、学习页面。
- `小程序端/微信开发者工具导入包`：最终微信导入目录，已组装原生地图、账户、导览和学习页面。
- `小程序端/源码`和`模块源码`：便于团队继续开发的源码。
- `services`：两端共用后端、账户、学习记录和资料服务。
- `视觉规范`：两端配色和组件规则，两端交付目录也各保留一份。

## 本地查看

使用 Node.js 24，在 V1 运行 `node 启动服务.mjs`，打开 http://127.0.0.1:3110/ 。已启动时不要重复启动。

微信开发者工具导入`小程序端/微信开发者工具导入包`。目前 AppID 为测试号配置；正式发布与真机联调仍需你们的 AppID、手机可访问的 HTTPS 后端和合法域名。本次没有完成微信真机验收。

## 已统一的界面

品牌统一为“山河有迹”。深朱红、米白、墨绿与淡金共用；标题、正文、按钮、卡片、表单、提示条、空状态及焦点样式统一。网页适配桌面与手机宽度，小程序保留原生页面、定位与地图能力。

五项底栏为：首页、人物、足迹、小迹、我的。长卷和学习保留页面入口；全国名单可从首页地图或人物索引进入。管理员审核仍通过账户权限控制。

全国地图支持拖动、缩放、复位、省份点选和省份目录。数字由同一份名单实时计算；省份→名单→条目资料可以连续访问。不同模块的人物 ID 不直接混用；目前全国名单的恽代英条目明确关联到深度档案 P007，其余未建立关联的条目保留基本资料页。

省界采用可逆编码缩小包体，全部点位及多边形、岛屿结构保持不变；缩放时按原始几何重新绘制。小屏标注避让，面积较小的省级地区也可通过目录选择。

## 数据边界

本次沿用第一部分程序的119条资料样本。正在补全的256人研究材料没有自动替换进程序；软件合并不代替资料审核。所有119条继续保持待独立复核，地图显示的是资料条目数，不是审核通过人数或全国历史总人数。没有把原先不同口径的官方概数混进地图。

生平、来源、题库、场馆开放状态、照片许可及地图使用条件沿用原标记，没有因合并而提升为已核验或已授权。正式公开前仍需相应核查。
