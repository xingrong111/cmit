# 江姐全景故事接入说明

已将成员4配音整合版的江姐故事合入V1，未覆盖其交付包内的其他人物、账户、学习页面和旧题库。

## 体验入口

- 网页：人物 → IP专项 → 江竹筠 → 针线里的黎明·互动故事。
- 直接访问：http://127.0.0.1:3110/#/pages/story/index。
- 江竹筠姓名资料页也有互动故事入口；旧江姐全景路由已指向新版。

构建使用Node.js 24。前端构建新增story-assets.mjs和mini-voice-assets.mjs；网关补充mjs与mp3的正确响应类型。
