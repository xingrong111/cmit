# 首次使用引导改进

## 当前体验

首页首次使用时展示四步欢迎导览：认识山河、走近人物、继续探索、选择起点。用户可跳过、返回上一步，并选择读人物、看全景或做挑战。导览阶段保持首页，最后才进入所选体验。

首页的使用指南入口与“我的→使用指南”进入同一独立页面，包含三条体验路线、七个模块操作说明、江姐互动故事入口及六项常见问题。指南可随时重看。

小迹使用指导已移除“人物、长卷、挑战尚未接入”的旧说明，并指向新的使用指南。

## 状态与兼容

本机状态键为shanhe:guide:v2，区分completed和skipped。保留旧版已完成用户的选择，不强制重新弹出。手动重看使用一次性请求，不重置真实阅读、挑战或荣誉记录。存储不可用时不阻塞公开阅读。

网页支持Esc关闭、键盘焦点约束与关闭后恢复滚动。小程序复用同一欢迎组件和指南页，导览期间隐藏原生底栏，关闭或离页后恢复。最终选项页完整显示三个入口；内容可滚动但不展示滚动条。
