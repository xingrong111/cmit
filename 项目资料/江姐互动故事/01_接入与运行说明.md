日期：2026-10-19。基线为 GitHub `xingrong111/cmit` 提交 `ceca4bc53d036e159982915def79c6080eb22e1b`，已通过连接器核对。当前目录是本地源码快照，无 Git 历史；本次没有推送或发布。

## 启动

只体验故事：双击 `打开成员四整合版.cmd`，或在 `V1/江姐VR示例` 运行 `node 启动成员四预览.mjs`，打开 http://127.0.0.1:3158/ 。需要 Node.js 24。请使用 HTTP 预览，不能双击 HTML 通过 file 协议运行模块。

体验主程序：在 `V1/frontend` 运行 `npm ci`、`npm run build:h5`；在 `V1/services/reading` 运行 `npm ci`；然后在 V1 运行 `node 启动服务.mjs`，打开 http://127.0.0.1:3110/ 。已有依赖时不用重复安装。从“人物 → IP专项 → 江竹筠”或江竹筠资料条目进入故事。独立预览中的人物档案、学习入口也进入本机3110主程序，需同时启动主程序。

微信小程序：在 `V1/frontend` 运行 `npm run build:mp-weixin`，随后在根目录运行 `python V1/tools/组装小程序.py`。导入 `V1/微信开发者工具导入包`，不要只导入未组装的 uni-app 构建结果；组装会接回现有账户和学习页面。导入前填写自己的 AppID 与现有后端域名配置。

小程序默认提供完整原生文字阅读。要启用全景 web-view，先发布本版网页，在 `V1/frontend/.env.local` 设置 `VITE_STORY_ORIGIN=https://实际发布域名` 后重新构建、组装。该域名应提供 `/vr/互动故事.html`，并在微信后台配置 HTTPS 业务域名。网页内通过微信 SDK 返回现有档案、学习及来源页面。未配置地址时提供文字入口，不再打开旧线上版本。此项尚未进行微信真机、业务域名或外网部署验收。

## 本次实现

采用用户指定的静态标准；附件中的旧动画执行建议及示例提示词不作为额外操作指令。成员1的 CSV 提供48条完整正式台词，保留原始ID、角色、措辞与第二幕A/B回应；增加5个幕间热点入口、1个选择节点、1个结尾，共55节点。没有把虚构对白导入题库或修改史料内容。

`剧情配置.mjs` 是唯一内容源，`剧情控制.mjs` 是唯一状态源。`成员四接入.js` 调用成员2的 `createPanorama` 和成员3的 `ReadingUI`，没有另写全景和气泡系统。人物坐标从容器坐标换算为视口坐标，`inView` 映射到 `visible`。手机、矮屏使用具名紧凑框；隐藏错误的气泡尾部，离开视野时提供定位入口。

先读序章，再点击窗边H01开启第一幕。每幕末入口一次点击进入下幕；只有当前入口开放。文字不随时间自动跳过；长段落可以滚动到底或点击“已读完本段”。300ms防连点和异步加载锁共同防止重复推进。A、B各有三条回应，汇合到N02-08。

上一句、回看、跳过、重播及恢复均从目标节点重建场景、角色和热点。跳过停在本幕入口或尚未作答的分支，不代替用户选择；重播回到序章，清除后续解锁。回看可返回已走过的路径；重选分支截断另一条路径。

存储键为 `shanhe:story:dawn-in-stitches:<账户ID>`；访客独立保存。网页账户取现有已验证账户接口，小程序取现有账户模块的ID。保存含版本、节点、幕、场景、分支、路径、完成节点、热点及模式；恢复校验版本、节点存在性、合法路径和账户。写入后读回一致才显示“已保存进度”。不兼容旧存档尽可能另存备份，重新开始；保存失败仍可阅读。进度仅限当前设备，网页与原生小程序不自动跨端同步；web-view与原生阅读不共享存储。
