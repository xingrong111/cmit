# 资料导入模板

`import-template.json` 是一张空表，用来提交还没核验的新资料。它不会把现有阅读库、150 道题或地点资料再导一遍。

服务运行后，也可以打开 http://127.0.0.1:3105/import.html 预览。这一页不在学习底栏里。确认后仍只存草稿。

在本目录运行：

```powershell
node import-check.js import-template.json
```

空表会提示「还没有可导入的条目」。`import-template.example.json` 只示范字段，文件里写了 `_example: true`，检查时会拒绝，不会存成草稿。示例里的句子不是史料。

检查只报告错误，不改你提交的文件。通过以后，另存到 `data/import-drafts/`，状态是草稿、待核验，`published` 为 false。这一步不发布，也不把题目标成已核验。题库管理页要等成员3的管理员登录接到服务端之后再做。

模板有七个数组：

- `people`、`facts`、`sources`、`events`、`relations` 用阅读库的英文蛇形字段。`review_status` 和 `publication_status` 只能是 `draft`。
- `places` 用地点资料的驼峰字段。`coordinate` 和 `opening` 写 `null`，`published` 写 `false`，`reviewStatus` 写 `draft`，`sourceIds` 写空数组。
- `questions` 用题库的中文字段，并加上 `reading_person_id`、`reading_fact_id`。题目 `状态` 只能是待核验。

三套编号不能合并：

| 用途 | 编号样子 | 写到哪里 |
| --- | --- | --- |
| 阅读库 | `P009`、`P009-S-001`、`P009-F-001` | people、sources、facts |
| 题库来源 | `QQB-S02`、`LYS-S01`、`LDY-S01` | questions 的来源ID |
| 地点和设计包 | `PLACE-WX-LDY`、`IP-LDY`、`L-S12`、`SRC-`、`FACT-` | 不写进阅读库或题库来源 |

设计包里的 `S01` 和题库里的 `QQB-S01` 不是同一条。事实、事件、关系引用的来源，必须出现在本次文件的 `sources` 里，不能只写一个阅读库里已经有的编号。

已有人物直接写编号，不要把人物整条再交一次。瞿秋白是 `P009`，宋振中是 `P004`，陆定一是 `P014`。江竹筠和狼牙山五壮士没有阅读库人物编号，题目的 `reading_person_id` 写 `null`。`reading_fact_id` 在成员2确认前也写 `null`。`unique_answer` 为「否」的事实，不能被题目拿来当唯一依据。

狼牙山五壮士是群体，不写成一条人物。籍贯没有直接记载就留空，不要从亲属推断。
