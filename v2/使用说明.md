# 山河有迹 v3.0 使用说明

本目录为当前整合代码，发布于 2026-10-23。`v2` 为沿用的工程目录名，版本号见 `VERSION`。

## 安装与启动

1. 安装 Node.js 24 或更新版本。
2. 在 `frontend` 运行 `npm ci`、`npm run build:h5`。
3. 在 `services/reading` 运行 `npm ci`。
4. 返回本目录，运行 `node 启动服务.mjs`。
5. 打开 http://127.0.0.1:3210/ 。

3210 为网页与接口统一入口；3211—3215 分别为阅读、账户、导览、学习和文创服务。关闭启动器即可停止其启动的各模块。

## 外部服务配置

地图和模型：将 `services/guide/server/.env.example` 复制为 `.env` 并填写自己的服务配置。启动器会读取导览模块的 `.env`。

邮件验证码：安装 Python 3，将 `services/account/account.env.example` 复制为 `account.env`，填写 SMTP 配置。在本目录运行 `node --env-file=services/account/account.env 启动服务.mjs`。没有配置邮件发送服务时，请先配置再进行注册验证。

私有配置、真实账户及评论、学习进度与文创领取记录不随 GitHub 代码分发；运行时由各模块创建或保存本机数据。不要将这些数据提交到公开仓库。

## 源码与交付副本

`frontend` 和 `services` 为日常开发入口。`网页端` 包含网页页面、源码及模块页面副本；主启动器实际读取 `frontend/dist/build/h5`，因此首次克隆仍需构建。`全景场景`、`江姐VR示例` 为场景资源与示例，`data`、`docs` 保留公开内容及来源说明。

小程序开发材料另存于对应目录，不作为本版本网页的启动条件。历史 `V1` 独立保留。
