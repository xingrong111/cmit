# 人物图片接入说明

首页推荐、人物索引共用PersonPortrait组件；人物档案顶部增加肖像区域。点击已通过审核的照片可放大，图注与来源按钮展示时期、使用依据并可复制原始网址。读取失败回退山水姓名占位。

资料位置：frontend/src/data/人物肖像.json，已为现有15人建立独立记录。填写src、caption、period、sourceUrl、sourceTitle、rightsEvidence；确认人物身份后设identityVerified=true，确认使用条件后设rightsApproved=true。组件只显示同时通过且有来源、图注、使用依据的图片。此开关是前端展示规则，不替代人工核验。

现有“人物合集/修订说明.md”“当前内容总览.md”仍明确媒体目验与使用条件待补，本次未把候选表中的链接视为已授权照片，15人暂时均保留占位。候选表包含导航图及非人物素材，不能批量直接导入。

照片应放在frontend/src/static/portraits并使用/static/portraits/...路径，优先本地合法保存的文件；外部网址还需微信下载域名配置。不要将晚年照片当青年服饰依据，不自动上色修复。后续IP与照片分开。

修改后重新构建网页、小程序，运行tools/组装小程序.py和tools/整理双端.py同步两端交付。
