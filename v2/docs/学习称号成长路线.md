# 学习称号成长路线

称号从按人物展开的13条展示记录，改为5个全局成长节点，每项每账户各获得一次。

|称号|条件|
|---|---|
|星火初学者|完成任意1组入门|
|追光探寻者|完整完成1组入门与进阶|
|山河寻迹者|完整完成2组入门与进阶|
|薪火传习者|完整完成4组入门与进阶|
|山河知音|完整完成全部5组入门与进阶|

每组入门5题、进阶8题，答完即完成，既有通关规则不变。人物进度保留在挑战页，称号页不再按人物重复排列。

兼容：旧称号和完成记录不删除。称号视图直接依据已有完成记录计算新路线；以后完成关卡时只追加尚未授予的全局称号，不重复发放。读取称号不写回或清空用户记录。

验证：既有学习规则测试5项通过；独立临时资料测试0/首次入门/1、2、3、4、5完整组的解锁阈值与历史记录保留；浏览器桌面、手机宽度均展示5节点和最多1个下一目标，返回学习正常。微信包已组装，未进行真机测试。
