# 人物与学习挑战更新说明

## 人物目录

- 人物页整合“全国名单、详细档案、IP专项”三个视图，支持姓名、别名、籍贯检索及全国名单省份筛选。
- 研究目录来自原始375条记录，并同步256人逐人核查表中已补充的日期、籍贯和分省线索。仍保留“待独立核验”，没有升级为审核通过记录。
- 375是记录数，存在同名记录，不作为去重后的自然人数。地区不明的记录单列“地区待核”，不凭活动地或父母籍贯分配省份。
- 15份详细档案单独按已有档案的出生地域分组，说明出生地域与籍贯的区别。全国研究目录没有包含所有详细人物，因此提供独立档案入口，不把缺失姓名简单加入统计。
- 瞿秋白、宋振中、陆定一可以跳转既有详细档案；狼牙山五壮士、江竹筠目前提供专项学习入口，未虚构完整档案或已完成的IP作品。五组专项不增加自然人数。
- 本轮没有把375条研究记录批量升级为地图统计；首页地图仍遵循原有样本口径。

## 学习挑战

- 保留每组“入门抽5题→完成后解锁进阶抽8题”的规则，答完即完成，不设置通过分数线。
- 修复人物主题页“待挑战、已完成”筛选对关卡不生效，以及空筛选导致人物标题丢失的问题。
- 大厅与主题关卡采用米白纸色、朱红重点、淡金边线和分步骤引导。双端保留续答、复习、来源回顾及账户进度。
- 网页答题补充进度条；网页与小程序在未选答案时禁用提交按钮，避免无效提交。
- 操作按钮缩为内容宽度、居中文字、统一间距并自动换行；答题选项保留适合阅读的左对齐。减少长按钮，保留触控面积。
