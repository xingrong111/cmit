# V1 八项功能与视觉完善

更新日期：2026-10-12。

|顺序|本轮实现|
|---|---|
|1 导航与骨架|桌面优先顶部专题导航，手机五项底栏；隐藏导览重复模块导航，足迹保留明确文化路线入口；模块页面采用固定外层骨架，内部单一滚动区域|
|2 小迹对话|多行提问、Enter发送/Shift+Enter换行、自动增高；输入框宽度统一，偏好折叠，手机形象卡片减少遮挡；等待文案只描述生成状态|
|3 按钮层级|主操作朱红、次操作浅色、编辑复制排序删除保留图标和可访问名称；加入路线呈现勾选状态；按钮目标大小及圆角统一|
|4 定位选点|浏览器真实请求位置权限，服务端腾讯转换WGS84至GCJ02；拒绝、超时、精度不足或配额失败提供手动地图选点；地图显示起点标记与确认按钮；原微信定位流程保留，路线加入地图起点确认|
|5 文化路线|起点、站点、预算结果分开；上/下移动、桌面拖动；调整后清除旧计算结果；路径视野覆盖实际路径点；停留预算与接口步行时长分别展示|
|6 场馆视觉|有许可照片继续署名展示；其他场馆使用原创场馆山水意象，明确非实景复原；保留开放未知、来源待复核等真实状态|
|7 模块关联|人物页可带人物范围问小迹、浏览关联场馆；未接入的人物不会冒充已收录专项史料；我的账户可返回本机阅读记录，明确不同存储范围|
|8 评论管理|授权管理员可隐藏已公开评论，填写原因并留历史；普通用户不可隐藏；作者可查看原因、修改重提后再次审核；网页近期处理记录与微信处理记录入口|

视觉使用统一宣纸色、朱红、灰绿、暖金与字体层级。手机卡片减少嵌套边框，场馆使用建筑线条与山水意象；动效主要用于选中和按钮状态，尊重减少动态效果设置。未使用大面积闪烁/粒子，也未编造模型内部思考过程。

## 验证与边界

阅读后端20项、导览后端65项通过，包含GPS坐标转换及额度失败的模拟测试。评论隐藏/越权/公共列表/作者原因/重新审核/旧版本冲突在独立数据库中检查通过。

网页美化检查分别覆盖390px和1440px：多行输入、无横向溢出、桌面底栏隐藏、偏好折叠、路线下移和起点确认控件。浏览器定位流程使用模拟坐标验证，没有申请或保存测试人员的真实位置，不代表真实设备GPS验收。微信源码已同步并组装，但实际键盘、map事件与隐私权限仍需真机验证。

真实腾讯步行规划的本轮没有再追加请求，保留之前单站成功、多站额度受限的记录。场馆附近位置不等于游客入口，当前开放状态仍需出发前确认。

字体优先系统字体，新增建筑意象为代码绘制；原始照片许可及AI形象标识保留。没有将示意图称为实景。

证据：美化页面检查.json、评论闭环检查.json、功能复查.json、阅读后端测试.txt、导览后端测试.txt、页面截图内小迹美化及路线美化图片。
