# 人物图谱完善说明

## 本轮实现
- 人物联系 / 时代关联双模式，主题与节点类型筛选。
- 从已有已核事实中选择26条联系，补入人物、学校、组织、刊物、地点、作品；每条保留事实ID、来源ID和原文摘读。
- 所有目标节点统一身份，双向查询同一条原始关系；展示方向明确，授课/介绍任教/介绍入党不会颠倒角色。
- 点节点打开阅读说明，网页为右侧栏、手机为底部抽屉；可查看原始出处、人物档案、事件片段。
- 可逐层展开有更多联系的节点，并返回上一层或回到最初人物。例如秦邦宪 → 解放日报 → 陆定一。
- 共有机构只表达人物各自与机构的联系，不产生人物之间的同事、朋友或会面关系。
- 少资料人物采用紧凑画布并提供现有史料摘读，未增造具体事件日期或交往。

## 数据约束
原始SQLite记录、资料核验状态和全国人物统计均未改写。补充索引位于services/reading/data/图谱补充索引.json。其证据原文必须与当前公开已核事实完全匹配；事实文字变更、撤回或来源转为草稿时，不继续显示旧补充联系。
图谱范围仍是本项目深度档案与有依据的相关对象，不表示已为全部全国收录名单建立关系网络。
接口GET /api/reading/people/:id/graph新增可选focus参数，只允许沿本图已连通对象展开；未知/无关节点返回404，接口仍只读。

## 双端交付
微信交付包采用已有跨端组件实现，未引入浏览器专属图谱库。用户新提供的高清徽章源图保留；仅在微信生成包中制作160像素徽章副本，并剔除未引用的徽章备份，防止主包超过2MiB。网页仍使用高清源图。
本轮没有发布公网网站；微信真机效果尚未验收。


## 关系长卷视觉调整（2026-10-19）
参考用户提供的轨迹长卷：米白山水背景、彩色曲线、圆点与错落姓名、小幅肖像。曲线只连接真实关系端点，不串联无关联人物；位置不表达年代顺序。手机保留可读比例，通过拖动浏览长卷。保留主题筛选、节点说明、出处、逐层展开与返回。


## 手动缩放
保留加减按钮，新增网页鼠标滚轮（包括触控板滚动）和手机双指捏合。滚轮以指针位置为中心，捏合以两指中点为中心，缩放限制20%至200%。单指及鼠标拖动、复位、节点阅读保持可用。网页原生触摸事件避免坐标偏移；微信端保留小程序触摸事件实现。桌面和手机浏览器模拟已验证，微信真机尚未验收。
