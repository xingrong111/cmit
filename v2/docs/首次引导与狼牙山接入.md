# 首次引导、新版IP与狼牙山接入

- 首次打开网站首页会显示七步引导：首页、人物、长卷、足迹、小迹、学习、我的。
- 可上一步、下一步、跳过，支持键盘Escape关闭；完成或跳过后本机不重复弹出。
- 我的 → 使用指南，可重新打开。结束返回打开指南前的页面。
- 人物 → IP专项 → 狼牙山五壮士 → 360°互动场景。
- 本地独立全景：http://127.0.0.1:3110/panorama/lys/场景预览.html
