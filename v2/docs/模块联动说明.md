# 模块联动说明

人物索引和人物档案使用明确编号映射：P009瞿秋白→QQB，P004宋振中→SZZ，P014陆定一→LDY。进入挑战时筛选对应人物，用户自行选择关卡，不自动开题。没有对应档案的团体及人物不伪造阅读链接。

事件末尾提供人物主题挑战与问小迹入口。此入口不表示该事件必定有对应题目。解析提交后可回顾人物史料，网页本次答题保存在服务端及当前页；从人物返回可继续。来源链接仍以每道题真实来源为准，不把整个档案称为该题直接证据。

结果页提供人物回顾与关联场馆。场馆筛选沿用已有审核关联；无结果不推测新增地点。首页、我的已有学习大厅入口。底栏仍为五项。

网页与微信均实现人物到主题挑战及学习回顾入口。微信需实际开发者工具和真机验收。小迹仅在已有的人物上下文入口使用人物资料，不在答题前提供答案。
