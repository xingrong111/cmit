# 配置与发布步骤

V1/部署配置.json仅填写公开配置：apiOrigin为后端统一HTTPS入口；miniAppId为微信后台真实AppID。不要把模型Key、地图服务端Key或AppSecret填入此文件。当前保留本机地址和游客AppID，未虚构正式配置。

先运行python tools/同步公共配置.py，再在frontend构建网页和微信包，然后运行tools/组装小程序.py、tools/整理双端.py。阅读构建保留VITE_API_BASE兼容覆盖，通常不要再单独设置，以集中配置为准。

修改人物映射只改人物关联.json。同步会检查阅读姓名与编号，未收录人物保留null。

上线前仍需配置后台合法域名、定位隐私说明、后端HTTPS与数据备份，删除或更换演示账户后验收。模型和腾讯私有配置继续在服务端，不进双端文件夹。跨设备同步尚未实现，当前仅账户分区保存本机书签与路线。
