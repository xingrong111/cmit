# 山河有迹 v3.0 更新说明

发布日期：2026-10-23。基于 v2.3 整合当前工作区代码，使用 `v3.0` 分支及同名版本标签保存。

## 本次整合内容

- 更新网页前端、人物与场馆展示及页面排版，合并当前已完成的界面说明精简和字号调整。
- 更新文化路线与地图交互，包含步行、驾车、公交、骑行方式切换，以及基于当前时间和停留预算的预计到达时间展示。
- 同步账户页面与头像展示、邮箱验证及评论相关调整。
- 同步江姐主题互动故事、全景资源、剧情控制及加载交互的当前实现。
- 同步导览、学习、数字文创等模块的当前代码和实际使用素材。
- 用本次通过构建的网页页面刷新 `网页端/页面`，并同步源码及模块页面交付副本。
- 更新仓库入口说明、版本信息与环境配置示例，保留旧版本材料供追溯。

本次上传为当前代码快照；并非上述每个模块都在 v2.3 之后重新开发。
