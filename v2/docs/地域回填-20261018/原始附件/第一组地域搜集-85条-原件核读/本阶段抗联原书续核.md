# 第一组地域搜集·抗联将领传原书续核

2026-10-16。实际打开并视觉核读于绍雄主编《东北抗日联军将领传》（黑龙江人民出版社，2009年10月第1版，ISBN 978-7-207-08456-9）的版权页、目录和人物正文。

P0145赵庆祥的籍贯由辽宁日报所载省级“辽宁籍”，细化为“辽宁省开原县马仲河镇泉眼沟（原文）”。原书第339页明确记载其为该地人，第340页续记1936年任东北抗日联军第八军第六师师长、1939年春牺牲，与任务名录姓名、职务和牺牲年相合。此项按已读出版物正文采集为B级，辽宁日报省级记载继续保留为旁证。未取得本人户籍或出生登记，不能据此填写出生地区、出生年或祖籍。

同书还给三项缺口提供了明确的核查边界：P0110柴阴轩第339页正文只载职务、1937年牺牲及桦川县七星砬子战斗地点，没有出生地区或籍贯，不能把牺牲地当籍贯；P0123陆希田目录列第149页，但公开电子页只有页眉，相邻页衔接表明人物正文漏页；P0126徐德民目录列第337页，公开电子页同样只有页眉，相邻页也显示正文漏页。后续已直接下载网站所用原始页图：两张图像文件本身均只有页眉、正文为空白，因此可确定缺失存在于该公开扫描副本；仍不能断言纸本原书没有地域信息。

另检索到《桓仁县志》目录确有李向山人物传略，网络人物页给出“桓仁县铧尖子乡东堡村”出生说法，但目前未取得县志该传原页，未写入主字段，只保留为下一轮待核候选。
