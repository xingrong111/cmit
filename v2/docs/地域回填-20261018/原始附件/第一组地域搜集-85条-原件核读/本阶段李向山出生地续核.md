# 第一组地域搜集·李向山出生地续核

2026-10-16。P0078李向山新增出生地区“辽宁省桓仁县铧尖子乡东堡村（传记原文）”。人物传记正文直接记“李相山，原名李瑞林，号祥山。1884年生于桓仁县铧尖子乡东堡村”；辽宁省文旅厅转载辽宁日报报道以“抗联一师副官李向山”确认军职身份，《桓仁县志》目录在人物传略中列“李向山”，本溪市政府不可移动革命文物名录列“华尖子东堡李向山旧居”。姓名、出生年、军职和村落证据能够交叉闭合。

直接出生地正文来自未标明原始文献的聚合页，县志人物传正文仍未取得，因此证据等级记B并透明保留转载层级。只填出生地区，不以旧居反推籍贯。李相山／李向山异写、原名李瑞林、号祥山写入附注；历史地名与现地址不擅自合并。

当前85条：出生地区33、籍贯55、祖籍3；两项均有17、至少一项71、仅一项54、两项仍缺14；出生地区缺52、籍贯缺30。7项既有主字段地域差异和3名身份缺口继续保留。目标继续进行，未取得证据的字段不猜填。
