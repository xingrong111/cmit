# 第一组地域搜集·邵存诚国史馆抚恤档案续核

2026-10-16。P0142邵存诚新增籍贯“江苏省宜兴县（两来源均列江苏宜兴）”。国家文化记忆库公开的国史馆数字对象《八年血债（二十六）》题名直接写“顾祝同电蒋中正第三战区司令部参谋处长邵存诚遭日机轰炸殒命，遗族家境清贫，拟请予以抚恤”，卷件日期1939年1月12日，与任务人物的职务和死亡年份闭合。国史馆元数据“相关地点”列“江西—吉安；江苏—宜兴”；吉安对应殉难事件地点，宜兴又与静思斋据所藏《黄埔同学总名册》摘录的埔高班条目“邵存诚（江苏宜兴）”一致。两来源在人物身份和地域上相互补强，按B级采集为籍贯；尚未打开国史馆原始电文大图，未标为户籍原件。

广东省档案馆黄埔六期原图中的“邵存诚、明仁、22岁、江苏兴化”不再作为本任务人物的主候选。该条按1926年22岁推算约生于1904年，与任务1902年有差异，且地域与国史馆／埔高班的宜兴相冲。它可能是同名人物或名册信息存在误差，现列“同名排除待定”，不强行拼接。

当前85条：出生地区31、籍贯52、祖籍3；两项均有16、至少一项67、仅一项51、两项仍缺18；出生地区缺54、籍贯缺33。谢家珣江西赣县主值继续保留。7项既有主字段地域差异和3名身份缺口继续保留；邵存诚的兴化档案作为同名排除待定另行展示。目标继续进行，未取得证据的字段不猜填。
