# 第一组地域搜集·辛力生籍贯续核

2026-10-16。P0122辛力生新增籍贯“辽宁省（陵园原文为‘辽宁人’）”。华北军区烈士陵园官方网站英雄事迹列表明确记：“辛力生同志，晋察冀军区第三军分区第十二大队政治委员，辽宁人……一九三八年七月牺牲于定县，时年二十九岁。”人民网发布的第三批著名抗日英烈正式名录则列“辛力生（1909—1938），八路军晋察冀军区第3军分区第12团团长”。稀见姓名、生卒年、军区及第十二单位共同对应，足以确认陵园条目为任务人物，故按直接“辽宁人”表述填省级籍贯。

证据没有细到县，也没有明确“出生于”，因此不细化县、不填出生地区。陵园的“第十二大队政治委员”与正式名录的“第十二团团长”存在军职口径差异，可能来自编制或任职阶段变化，也可能是碑文差异，本阶段不擅自解释，继续列为身份附注。

当前85条：出生地区32、籍贯55、祖籍3；两项均有17、至少一项70、仅一项53、两项仍缺15；出生地区缺53、籍贯缺30。7项既有主字段地域差异和3名身份缺口继续保留。目标继续进行，未取得证据的字段不猜填。
