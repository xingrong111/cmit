# 王子阳原籍报道续核

2026-10-16。新增王子阳籍贯采集值“哈尔滨市五常（报道原文）”，依据黑龙江省文化和旅游厅2025-09-11转载哈尔滨新闻网《热血沃黑土，“拐把桥战斗”遗址留忠魂》，实际打开正文第38行明确“王子阳是哈尔滨市五常人”。来源A级官方转载报道，全部待独立复核。不是根据五常背荫河关押地点推定。

文汇报王彦／上观新闻2025-09-19文章仍称“他的原籍和生年已很难考证”，没有给出另一具体籍贯，已作为可考性另载并列记录。新增值属于明确报道采集，未获本人户籍、原籍登记或家属档案，不能称原籍已最终确认；出生地区仍未找到。官方转载所引兰会田回忆录记1936年4月战斗牺牲，与名录及上观文章1937年不同，日期和三／六师职务差异另存，原姓名、出生日期主值均不改。

身份以背荫河逃生、参加抗联、六师代师长、拐把桥牺牲和寻墓追认这一组独特事件核对，排除神父及1914—2007年莱西籍等其他同名人物。百度摘要仅用作追原报道线索，未把百科摘要当原件。

当前85条：出生地区30、籍贯49、祖籍3；两项均有16、至少一项63、仅一项47、两项仍缺22；出生地区尚缺55，籍贯尚缺36。7项既有主字段地域差异保留，另有资料可考性、日期及候选差异需要复核。全部信息尚未查齐。
