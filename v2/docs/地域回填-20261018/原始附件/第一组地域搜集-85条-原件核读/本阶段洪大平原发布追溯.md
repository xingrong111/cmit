# 洪大平原发布追溯与地域缺项续核

2026-10-16。已从凤凰转载追到江西日报2025年9月12日6版李歆原稿的原发布网页，实际读取正文，新增A级地方主流报刊来源。洪大平县级籍贯“江西省永新县”保持，出处不再仅依赖转载；原稿与转载属于同一证据链，不算独立互证。

该原稿采访永新县退役军人事务局局长，明确自然村与户主仍难具体确认。这与纪念网9月16日转载江西新闻联播所称9月4日已确认夹山村，仍有报道时效或调查状态差异。现有正文无法说明其原因，未直接采纳夹山村。出生地区也未见明确记载，继续空缺。原始履历表材料链接尝试打开失败，未辨读照片；电子报PDF同样未成功读取，不称原版核读。

杨法震已有电视台纪录片转载候选，但未找到原发布出生地正文，保持候选。郑桂林的官方人物页入口实际打开502，旧凤凰文章打开失败；不把维基所引原页当作亲见。其他本轮检索未取得可新增主字段的本人地域证据。

陈芳钧新增“黑龙江双城县人”的明确籍贯措辞候选，来自《小兴安岭抗日斗争“四个一百”之百名英烈（二）》NO.59。本文已实际读取，但搜狐账号为“大东北生活资讯”，文末虽标伊春市老促会来源，原发布仍未取得，故C级候选、主籍贯仍未找到。姓名、1906年、矿警起义及六军二十九团任职和1939年2月23日牺牲事件共同对应；未用现有出生地自动回填籍贯。前半篇也已读，未检出本表其他缺项的新增明确地域依据。

当前仍为85条：出生地区30、籍贯48、祖籍3；两项都有16、至少一项62、两项仍缺23，7项主字段地域差异保留，此外候选差异和身份缺口继续逐项追索。全部待独立复核，整体目标未完成。
