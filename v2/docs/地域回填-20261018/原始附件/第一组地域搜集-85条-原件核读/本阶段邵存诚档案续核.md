# 第一组地域搜集·邵存诚黄埔档案原图续核

2026-10-16。广东省档案馆开放档案页取得“邵存诚”黄埔军校第六期档案，档号G2013-黄埔军校-14543。两张原图已逐字核读：炮科中队部同学录表格列邵存诚、别号明仁、22岁、江苏籍并附兴化通信地址；肖像页下方更明确列“邵存诚 明仁／年二十二 江苏兴化”。该原图本身是A级籍贯材料。

本轮仍未把“江苏兴化”写入P0142主籍贯。原因是可访问材料虽能分别证明黄埔六期同名炮科学员和第三战区司令部参谋处处长邵存诚，但尚未找到履历表、军官名录、褒扬令或人物传直接以别号明仁、黄埔期别等唯一特征把两段经历相连。仅凭同名、军人背景和年代相容，证据仍有一处身份桥缺口。现将“江苏省兴化县”列为A级原图支持的待核候选，后续重点追索黄埔毕业生调查表、陆军大学十一期同学录、第三战区职员录及国民政府褒扬档案。

上一阶段谢家珣籍贯“江西省赣县”继续保留，其身份已由同名同籍贯的第87师野战补充团团长条目闭合。当前85条统计不变：出生地区31、籍贯51、祖籍3；两项均有16、至少一项66、仅一项50、两项仍缺19；出生地区缺54、籍贯缺34。7项既有地域差异和3名身份缺口继续保留。目标继续进行，未取得证据的字段不猜填。
