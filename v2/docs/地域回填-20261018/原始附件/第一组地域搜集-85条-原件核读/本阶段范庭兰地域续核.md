# 第一组地域搜集·范庭兰地域续核

2026-10-16。P0143范庭兰新增出生地区、籍贯，均为“河南省温县”。《抗战牺牲将领—范庭兰》使用任务同字姓名，明确记“字雅轩，河南温县人”和“豫北别动第五总队少将总队长”；正文又说明九十七军统编后由豫北抗日游击第八别动大队改编为第五总队。《范廷兰》使用“廷”字，明确记“1903年2月20日出生于河南温县”，并载字雅轩、第一战区游击第四总队及修武作战经历。再结合此前已读《国民党抗战骁将》范廷兰条的河南省温县人记载，姓名异写、同字、出生年、地域、部队和战斗经历已形成可解释的身份链，故出生地区与籍贯升级进入主字段。

争议没有删除：资料存在“范庭兰／范廷兰”“豫北别动第五总队／第一战区游击第四总队”和“1938／1939年”差异；其中一页首段写1938年牺牲，后段叙事又写1939年2月至3月作战，网页内部亦矛盾。本阶段只确认地域，不改原任务姓名、出生日期或卒年，仍需抚恤原档、地方志原页或本人登记原件审定规范姓名和时间线。

当前85条：出生地区32、籍贯54、祖籍3；两项均有17、至少一项69、仅一项52、两项仍缺16；出生地区缺53、籍贯缺31。7项既有主字段地域差异和3名身份缺口继续保留。目标继续进行，未取得证据的字段不猜填。
