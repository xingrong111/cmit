# 戴克政籍贯细化与全书检视

2026-10-16。本轮将戴克政籍贯由“敦化市”细化为“吉林敦化县沙河沿（原文）”。依据张彦夫、杜宝君《满门忠烈：戴氏家族举家抗日英雄事迹》（抗日战争纪念网2018-05-29）实际正文，引述周保中日记称本人“吉林敦化县沙河沿人”。这是署名研究文章的二手引文，B级采集、待独立复核，不称亲见日记原件。

文中另载戴克政出生日期1916年2月17日，与原任务1915年不一致，已单列另载候选，原日期保持。文章主语为其父戴万龄的“祖籍山东省莱州府掖县”保留为家族祖籍线索，不自动填入戴克政本人祖籍；学习地点、家宅和当地活动均不推出生地。

又按85人姓名检查《国民党抗战骁将》206页电子排印本，检出范廷兰条185页、杨家骝条201页。前者继续作为异名待核候选；后者“贵州省荔波人，一九○五年生”没有明确出生地点，不将籍贯复制为出生地区。本次全量只指这一本的文字检视，不表示85人的全部史料已经查完。

人民日报2025-09-15第20版《血脉》（孙翠翠）支持戴家亲属关系及敦化沙河沿家族活动，无戴克政明确出生地或本人祖籍字段。延边新闻网2026-09-18新专文搜索摘要可见，但实际打开超时，未据摘要填写字段。下一步追周保中日记本人条的原页、敦化本人登记及家族迁徙原件。
