# 第一组地域搜集·谢家珣黄埔档案原图续核

2026-10-16。P0116谢家珣新增籍贯“江西省赣县（档案原文为江西赣县）”。广东省档案馆开放档案页题名“谢家珣”，成文日期为1926年第五期，档号G2013-黄埔军校-07581。两张原图经逐字核读：同学录表格列姓名谢家珣、别号美东、年龄二十二、籍贯江西赣县，通信处为江西赣县沙石埠邮转；人物肖像页再次列名“谢家珣”，并重复美东、二十二、江西赣县等信息。

身份衔接方面，《抗战殉国军官录》的同一条记“陆军第八十七师野战补充团上校团长谢家珣，追赠陆军少将（江西赣县人 南京）”。这与任务中的第71军第87师补充旅补充团团长身份相接，也与黄埔五期档案的少见全名、年代和籍贯一致。该军官录网页注明转自《抗日阵亡将士录-搜狐博客》，因此只按B级辅助使用；籍贯主值以广东省档案馆原图为A级依据。尚未取得本人户籍或出生登记，故不填出生地区；“沙石埠邮转”是通信处，未外推为出生地、村级籍贯或祖籍。

当前85条：出生地区31、籍贯51、祖籍3；两项均有16、至少一项66、仅一项50、两项仍缺19；出生地区缺54、籍贯缺34。7项既有地域差异和3名身份缺口继续保留。王俭、李向山等仅有未溯源聚合页的村级说法仍保持候选。目标继续进行，未取得证据的字段不猜填。
