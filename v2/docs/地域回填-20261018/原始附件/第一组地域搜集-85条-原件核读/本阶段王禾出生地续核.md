# 第一组地域搜集·王禾出生地及方志候选续核

2026-10-16。P0085王禾新增出生地区“河北省保定市涞源县上庄村（报道原文）”。央广网2026年4月4日报道由记者王艺霖、实习记者郭浩楠在王二小红色教育展馆采访，上庄乡党委委员、组织委员杨美霞站在展馆史料墙前明确说明：“本名叫王禾，1929年就出生在我们脚下的上庄村。”报道同时写明王禾即王二小、13岁牺牲、2025年进入第四批著名抗日英烈名录，与任务记录对应。按A级官方媒体实地采访采集出生地区；仍未取得出生登记，不将出生成长地自动填作籍贯或祖籍。

本轮另形成两项待核候选，均未进入主字段。P0100王俭的公开人物页记“1914年生于方正县二吉利村”，并载第三军第一师第一团团长和1937年牺牲，身份相合，但网页没有注明原始编纂来源；需取得《方正县志》人物传或烈士纪念碑档案原页。P0078李向山的聚合页记“1884年生于桓仁县铧尖子乡东堡村”，并称原名李瑞林、号祥山；《桓仁县志》公开目录确有“李向山”人物传略，但正文未公开，且“李相山／李向山”字形关系仍需原页确认。

当前85条：出生地区31、籍贯50、祖籍3；两项均有16、至少一项65、仅一项49、两项仍缺20；出生地区缺54、籍贯缺35。赵庆祥县镇村级籍贯细化、柴阴轩无地域字段、陆希田和徐德民电子书缺页等上一轮结论全部保留。7项既有地域差异和3名身份缺口继续保留。目标仍在进行，全部采集值待独立复核。
