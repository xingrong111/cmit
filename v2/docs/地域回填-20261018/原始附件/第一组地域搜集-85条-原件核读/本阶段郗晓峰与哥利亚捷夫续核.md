# 第一组地域搜集·郗晓峰与哥利亚捷夫续核

2026-10-16。本阶段没有新增主字段，但形成两组可复核的身份与来源缺口。

P0156郗晓峰：公开人物镜像页写“郗晓峰（1910—1940）陕西蓝田县人”，并列八路军一一五师民训部、中共完县工委、晋察冀边区三地委组织部及曲阳牺牲经历，页面自称来源为保定市地方志办公室。人民网陕西频道转载的家属采访又以孙子郗选、中共蓝田特别支部遗址和白鹿原活动补强人物对应。但任务正式名录写1906—1940，镜像页写1910—1940，且原始方志页尚未取得。因此“陕西省蓝田县”只列籍贯候选，不进入主字段；孙辈老家和本人活动地不反推本人籍贯。

P0125哥利亚捷夫：已读取俄罗斯中央空军博物馆公开的在华牺牲苏联志愿航空人员名单，逐段核对俄文字母Г及1938年条目，未找到可直接对应中文名的Голядьев／Голядев。近音条目ГУЛЫЙ Филипп Денисович虽为1938年在华牺牲飞行员，但没有中文名—俄文全名桥接，不能认作同一人。南京抗日航空烈士纪念馆公开说明确认哥利亚捷夫在五名已入选中国著名抗日英烈名录的苏联航空英烈之列，同时说明236人名录资料仍有缺漏并在持续勘误；公开页未给其俄文全名和出生地。因此两项地域继续留空。

当前85条：出生地区32、籍贯54、祖籍3；两项均有17、至少一项69、仅一项52、两项仍缺16。7项既有主字段地域差异和3名身份缺口继续保留。目标继续进行，未取得证据的字段不猜填。
