# 第一组地域搜集·马天民籍贯续核

2026-10-16。P0131马天民新增籍贯“山东省长山县北旺庄村（今淄博市周村区北旺村）”。《周村区志》第五章乡镇在张坊乡条下明确记载：“北旺庄村是八路军山东纵队第三支队司令员马耀南及其弟马晓云、马天民三烈士的故乡。”山东抗日战争纪念馆2015年报道又称马耀南、马晓云、马天民是“周村城东北旺村马家三个亲兄弟”，并单列马天民1910—1939、又名马方普、第五军第一支队队长等经历，与任务人物闭合。二者共同支持北旺庄村为籍贯。

行政地名按时间分开处理：历史籍贯写长山县北旺庄村；《周村区志》编纂时归张坊乡，2015年报道写北郊镇北旺村，现行概括只到淄博市周村区北旺村，不把不同时点乡镇名称并列成一个现行地址。上一阶段已证祖籍“长山八区沟西庄（报道时称邹平县西董镇沟西村）”继续保留在祖籍栏，不与籍贯合并；出生地区仍未找到。

当前85条：出生地区31、籍贯53、祖籍3；两项均有16、至少一项68、仅一项52、两项仍缺17；出生地区缺54、籍贯缺32。邵存诚江苏宜兴、谢家珣江西赣县主值继续保留。7项既有主字段地域差异和3名身份缺口继续保留。目标继续进行，未取得证据的字段不猜填。
