# 山河有迹图标更新

参考用户提供图例的暖金色、文旅插画感与轻层次，重新绘制19款原创功能图标，未裁取截图中的品牌或成套素材。

采用米白、暖金、朱红、墨绿统一配色。首页为山水，人物为档案册，足迹为地图定位，小迹为导览员与对话框，长卷为卷轴，图谱为关系节点，学习为书卷旗帜，荣誉为勋章，评论为留言纸笺，账户为档案名片。

接入范围：五项底栏、桌面导航、首页功能入口、个人简介快捷入口、阅读链接、关系图谱节点、我的阅读菜单、AI导览场景、足迹与路线标题、学习大厅及荣誉、账户标题。复制与修改图标同步调整；发送与停止保留简洁高对比形状。

原始SVG和跨端PNG位于`frontend/src/static/icons`。PNG为透明背景80×80，包含普通与选中导航状态；功能名称仍以可读文字展示，装饰图像不重复朗读。图标不承担唯一状态提示。

网页与小程序共用同一图形系统，保持原有点击事件、路由和功能逻辑。真机显示仍需独立验收。
