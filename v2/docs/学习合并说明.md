# 学习挑战合并说明

更新日期：2026-10-13。原独立工程保留，合并内容在V1。

## 功能与入口

网页：http://127.0.0.1:3110/#/pages/learning/index 。首页和我的均有入口。微信导入V1/微信开发者工具导入包，不能只导入编译中间目录。

接入五组150题，包含大厅、答题、解析、结果与称号。每组入门抽5题、进阶抽8题，完成入门再解锁进阶。答完即完成，不设置分数线。题目仍待核验，本次软件合并不代表历史依据审核通过。

## 账户与管理

使用成员3的同一账户。匿名开始挑战转到登录，网页登录后返回学习页。后端从会话取得账户ID，不接受客户端指定他人身份；其他账户不能读取或提交答题。切换账户清除前端旧答题缓存。

进度保存于services/学习/data/progress.json，服务重启后保留。原独立演示中匿名随机编号的进度不自动迁移，避免归属不明。

网页管理员工作台提供题库草稿和资料导入入口，相关接口要求管理员身份。保存仍是草稿，不自动发布。微信已合并学习流程；编辑与导入工具使用网页端。
