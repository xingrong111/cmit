# 地图与人物检索-最终交付包

## 一、文件夹用途

本文件夹是“地图与人物检索”微信小程序项目的最终整理版本，包含项目源代码、云函数、数据资料、网页构建产物和项目配置文件。

当前文件夹已去除嵌套的旧交付包和临时缓存，仅保留一套最新内容。

## 三、重点内容说明

### 1. 山河地图

首页地图代码位于：

`src/pages/index/index.tsx`

地图支持：

- 展示中国省级行政区地图；
- 点击省份后进入对应人物名单；
- 鼠标或触摸省份时显示省名和参考人数；
- 支持地图拖动和缩放；
- 省界采用细窄、低对比度的暖米白线条；
- 地图外轮廓使用朱红色线条；
- 微信小程序 Canvas 和网页 SVG 地图保持一致。

地图统计数据位于：

`src/data/fixtures.ts`

其中的地图人数属于参考统计数量，与小程序中实际收录的人物名单数量不是同一统计口径。例如广东地图参考数量为 **13**，不代表当前名单一定有 13 名人物。

### 2. 人物名单

人物数据和人物记录位于：

`src/data/fixtures.ts`

人物查询逻辑位于：

`src/data/getPeople.ts`

人物页面位于：

`src/pages/people/index.tsx`

当前人物名单依据已核验的省份归属整理。省份归属以籍贯和历史行政区划证据为依据，不以活动地点或收录单位所在地直接推断籍贯。

### 3. 统计研究资料

`各省英雄人数统计` 文件夹保存了人物来源、籍贯归属、时间条件、去重排除、分省统计和争议事项等研究资料，可用于追溯小程序中的人物和地图统计依据。

其中：

- `04_籍贯与省份归属证据.csv`：省份归属核验依据；
- `06_分省统计结果.csv`：分省整理结果；
- `08_各省英雄人物数量表（1919-1949）.csv`：地图参考数量来源；
- `英迹_山河英雄谱_全国英雄人物统计资料库.xlsx`：研究资料汇总表。

### 4. 云函数

云函数位于 `cloudfunctions` 文件夹，需要在微信开发者工具中按云开发环境部署：

- `getPeople`：获取和筛选人物资料；
- `getProvinceStats`：获取各省地图统计；
- `getStatisticsExplanation`：获取统计口径和覆盖范围说明。

### 5. 网页静态阅读版

`dist` 文件夹是已经构建完成的网页静态版本：

- 使用浏览器打开 `dist/index.html` 可查看网页版本；
- `dist/js` 保存网页脚本；
- `dist/css` 保存网页样式。

## 四、开发与构建

在项目根目录执行：

```bash
npm install
npm run dev:h5
```

构建网页静态版：

```bash
npm run build:h5
```

构建微信小程序版本：

```bash
npm run build:weapp
```

构建完成后，可使用微信开发者工具导入对应的微信小程序构建目录。

## 五、交付注意事项

1. `src` 是后续维护和修改的主要代码目录。
2. `dist` 是网页构建产物；修改源码后需要重新构建才能更新网页版本。
3. 修改人物或省份统计后，应同时核对 `src/data/fixtures.ts` 和 `各省英雄人数统计` 中的研究资料。
4. 地图参考数量和小程序实际人物名单数量应分开理解，不能直接相互替代。
5. 部署云函数前，应确认微信开发者工具中的云开发环境已配置完成。
6. 当前文件夹不包含 `node_modules`、`.pai`、`.swc` 等临时或缓存目录。
