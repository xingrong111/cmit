# 接口与团队合并

## 与其他成员的边界

本模块不实现重复登录/角色选择，不提供发布和审核写接口。当前只有公开阅读接口，试读服务默认仅监听电脑回环地址。成员3的登录、审核、管理员权限在主项目维护；不要在客户端让用户自选管理员。

成员2提供审核后的 `personId/eventId` 和人物链接；成员5提供逐条事实、场馆与来源证据。本模块不读取全国人数统计、不把团体另增加一个自然人。现有 `IP-QC`、`IP-LDY` 是原设计使用的ID，团队最终以主数据ID表为准，映射修改事实与地点两处，不能仅改显示名称。

## 合并微信主工程

1. 把 `pages/assistant`、`radar`、`place`、`route`、`source`、`privacy` 复制到主工程。若已有同名页面，先改路径并同步所有跳转，避免覆盖。
2. 合并 `utils/api.js`、`utils/location.js`、`config.js`。默认独立工程采用这些模块名；主工程如同名，使用独立子目录并修正 `require`。
3. 主 `app.json` 注册6个页面，合并位置permission和 `requiredPrivateInfos`。不覆盖原来的首页、tabBar、其他权限。
4. 合并 `app.js` 的 `globalData.position`、`routeIds`、隐私处理。主工程已有统一隐私处理时使用主流程，不注册两套监听。
5. 主题在独立工程 `app.wxss`。合并时给本模块根容器增加专属样式前缀后调整选择器，避免 `.card/.row/.title/button` 影响其他页面。当前CSS为独立工程全局样式，不能直接宣称无冲突。
6. `config.teamPages` 填入真正的主工程人物、事件、时间线、检索页面路径；这些目标页接收 `personId` 或 `eventId`。未配置时明确提示，不创造假入口。
7. 主导航“足迹”链接到 `/pages/radar/index`；AI按钮链接到助手页。不要把足迹雷达替换首页统计地图。

人物入口示例（团队主工程调用）：

```javascript
wx.navigateTo({
  url: '/pages/assistant/index?personId=' + encodeURIComponent(person.id)
    + '&name=' + encodeURIComponent(person.name)
});
```

微信页面query参数由框架解析，助手页不重复decodeURIComponent，避免名称含百分号时崩溃。事件上下文可使用 `eventId`。

## 后端接口

统一UTF-8 JSON；错误格式为 `{"error":{"code":"...","message":"..."}}`。默认同一IP每分钟最多30次 `/api/` 请求，供单实例联调用。不会返回密钥。

| 方法与路径 | 输入 | 成功内容 |
|---|---|---|
| GET `/health` | 无 | `{ok:true}` |
| GET `/api/config` | 无 | 试读/公开模式、服务配置布尔值、可浏览城市、内容标识 |
| POST `/api/chat` | `question`，可选 `mode:history/help, personId,eventId` | answer、citations、factIds、actions、status、mode、modelStatus |
| GET `/api/places` | 可选city/type/q；附近用lat、lng、coordinateType=gcj02、radius | items、total、mode、notice |
| GET `/api/places/:id` | 场馆ID | 详情、来源、是否可导航、最新开放状态 |
| POST `/api/routes` | origin和1—4个placeIds | 平台、汇总距离/分钟、legs分段、实际坐标路径 |

请求示例：

```json
{"question":"瞿秋白有哪些求学经历？","mode":"history","personId":"IP-QC"}
```

```json
{"origin":{"latitude":31.5,"longitude":120.3,"type":"gcj02"},"placeIds":["PLACE-WX-LDY"]}
```

第二个例子只是请求格式示例，**不是已核现场起点**。当前陆定一地点入口为空，该请求应得到409，而非路线。

城市筛选与附近筛选可以分别使用。城市不填坐标时所有已接入场馆可阅读；附近只返回入口坐标已核条目。`distanceMeters` 是直线距离，`route.distanceMeters` 才是道路步行距离。

回答状态：`answered`、`insufficient`、`boundary`。回答模式：`help`、`sources`、`model_selected_sources`、`sources_fallback`。`sources` 是检索模式，不伪装调用模型。来源不足不需要作为500异常显示。

常见错误：400输入问题/坐标/站点无效，404未公开场馆，409坐标待核或暂停开放，422站点跨度过远，429请求频繁，503地图未配置，502平台返回异常。客户端显示服务端中文提示。

## 后端合并

`createApp()` 是独立Node HTTP服务，不是Express路由。团队统一服务可先通过反向代理映射 `/api/chat`、`/api/places`、`/api/routes`，或提取 `assistant.js/routes.js/domain.js` 到主项目的控制器。不能把HTTP server对象直接当Express Router注册。

当前资料读取JSON并在启动时校验，修改后重启。没有数据库、上传资料、用户内容发布或管理后台。正式多人部署建议由团队统一内容仓库/数据库、网关认证、分布式限流和监控，保留同样的发布门禁。
