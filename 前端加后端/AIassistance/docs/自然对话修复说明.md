# 小迹自然对话修复说明

原问题：大模型只选择史实或操作指导ID，普通提问也被强制送入资料检索；前端未传最近对话。

本轮修改：普通聊天接入GLM自然回答；身份为小迹；前后端传递最多8条、每条600字的近期上下文。身份、问候和称呼记忆的普通文本回复兼容GLM未按JSON输出的情况。其他问题仍通过意图分类分流；历史资料不采用分类回复中的未经核验正文。

功能场景不再强制覆盖当前问题：即使选择“文化探索”或“史料问答”，问“你叫什么名字”也可以聊天。历史人物追问可沿最近明确人物继续检索；泛泛“是谁”等词不再直接匹配任意人物。

历史与地点信息仍保留原始来源及入口核验约束；日常聊天不标为史实已核验。会话不在服务器持久保存，前端已说明近期消息会发送给模型服务。资料管理和导航数据未变动。

验证：50项Node测试及28项浏览器检查通过；静态32个JS、10个JSON、7个WXML通过，尚未真机验证。
真实接口曾成功返回“我叫小迹，是‘英迹·山河英雄谱’的原创AI导览助手”，model_chat、available。随后接口返回HTTP429/1305，本轮显示调用限制而不声称没有历史资料。真实接口检查JSON只含人工测试示例，不包含用户真实聊天或密钥；该文件记录最近一轮结果，若显示fallback即不是模型生成回答。

预览更新后按Ctrl+F5刷新。可测试“你叫什么名字”“请叫我小陈”“你记得怎么称呼我吗”“我今天学习有点累，给我一些建议”。等待模型调用限制解除后再做连续实时测试。
