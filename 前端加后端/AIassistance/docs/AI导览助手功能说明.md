# AI导览助手

助手覆盖小程序使用指导、历史地点探索、文化路线建议、人物与事件资料问答，以及来源、隐私和权限帮助。默认“智能导览”自动判断问题；“使用与路线指导”明确进入导览分支。

示例：“这个小程序怎么使用？”“无锡文化路线怎么安排？”“我只有一小时，怎么选择参观地点？”“想少走路，需要提前确认什么？”“瞿秋白有哪些求学经历？”

导览分支调用服务端GLM接口，根据问题和已接入资料选择操作步骤、地点及建议顺序；后端检查返回ID，组装说明及可点击的地点、足迹、路线入口。不是只改名称，也不是固定回复冒充模型调用。历史问答仍采用模型筛选有来源的事实，保留原始证据。

已支持本次会话中城市、时间和步行偏好的连续补充与修改；不是完整聊天历史记忆，刷新或新导览会清除。人物选择限制历史问答，不限制一般软件导览。

模型调用失败时显示基础指导或检索结果。路线建议不是最短路、道路导航或时间承诺；真实路线由腾讯地图接口计算。未核验入口、开放、票价及无障碍设施不作保证。当前已接入无锡、常州5处场馆资料，尚未完整接入全部人物和景点。

六栏导航及风格保留，团队栏目尚未接入的入口如实提示。定位授权仍由用户点击触发，模型建议不会自动获取定位、加入路线或导航。

本轮29项自动化测试通过。实际本地服务请求“无锡文化路线怎么安排？我只有一小时。”返回 HTTP 200、`model_guidance`、`modelStatus=available`，验证本次确实使用了配置的GLM；不代表所有后续请求均不会遇到超时或额度限制。
