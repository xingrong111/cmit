# 小迹对话体验优化

2026-10-11，原生小程序与浏览器预览同步。

- 普通回答优先直接回应，默认简洁，避免反复自我介绍；详细或简短要求交由模型结合近期上下文理解。
- 用户消息增加“修改提问”，恢复原文到输入框，由用户编辑后发送。
- 助手消息增加“复制回答”；原生文本支持选择，史料出处与地点操作保留。
- 对话开始后场景选择变成紧凑样式，减少消息阅读区的干扰。
- 等待超过8秒显示“回答仍在生成”，支持停止；不伪造生成进度或逐字流式输出。
- 手动重试旧问题会舍弃其后的消息，并恢复那次提问的模式、人物及路线偏好。此前正常上下文保留；无自动反复请求。
- 等待过程中向上阅读旧消息，完成后不强制滚动，提供“查看最新回答”入口。
- 页面卸载与请求结束清理等待计时器，防止后台持续更新。

验证：54项Node测试、33项浏览器检查通过；静态检查通过。新增验证覆盖重试旧问题的历史顺序、上滑阅读不强制滚动、修改提问回填、回答复制入口。仍未进行微信真机测试。模型口吻调整已通过模拟接口回归，没有以真实GLM请求大量消耗额度；实际措辞由模型和服务可用性决定。

更新后强制刷新预览并点击“新导览”。没有新增聊天持久存储，近期会话随请求发送模型的原有说明保留。
