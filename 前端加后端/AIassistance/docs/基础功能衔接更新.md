# 基础功能衔接更新（2026-10-11）

本轮完善独立小程序与浏览器预览：

- 地点详情进入助手时传入地点ID与城市。导览回复围绕当前地点；人物问答仍遵循资料依据。
- 记住上次推荐地点，支持“换一个／第二站”排除前次地点。“第二站”是新建议，不表示自动规划或加入第二站。
- 建议增加“加入路线”按钮，只在用户点击时添加；最多4站，重复添加有提示。
- 已选地点ID与顺序保存在本机，可恢复、改序、移除及清空；定位不保存到本机。浏览器使用localStorage，小程序使用微信本地存储。聊天与导览需求仍只保存在当前会话。
- 腾讯步行接口区分IP未授权、每日额度耗尽、无路线和一般服务失败；模型不可用仍降级。历史错误提示由后端安全文本返回，不暴露密钥。
- 后端同时最多运行2个问答、2个路线计算请求，超出返回繁忙提示，取消／失败后释放名额；已有每IP频率限制继续生效。

仍未实现：服务端路线持久化、完整聊天历史推理、自由口令删除或修改路线、地图响应缓存、独立资料导入管理后台。地点数据继续通过JSON与现有校验脚本维护；外部资料收集不自动升级为公开已核验。

仍需外部条件：手机可访问的开发地址、发布用HTTPS和合法域名、游客入口核验、地图额度，以及微信开发者工具／真机测试。这些没有伪装成已完成。


验证：34项自动化测试、18项浏览器交互检查及静态语法检查通过。本地服务已重启到新版；尚未经过微信编译或真机检查。
