# 地点资料独立核对包核查问题

核对日期：2026-10-11。对照范围是本文件夹里的五处场馆档案、来源索引、入口记录和 06 继承资料。下面“已打开”指本次重新打开网页或查看包内图片后读到的正文，不是沿用资料包自己的“已取得”标记。

## 结论

五处场馆的主地址、瞿秋白和张太雷的开放时段、张闻天 1975 年迁居，和本次打开的页面一致，不能把整包判成不可用。有五处会让人跟错来源，或把资料包里互相打架的过程记录当成已核事实。当前开放、游客入口坐标、图片公开展示，资料包自己也没有批准，这几项应继续保持未批准。

## 需要改正

### 1. 秦邦宪的展陈句和“青少年居所”没有挂在所引来源上

`01-逐地点档案/秦邦宪故居.md` 写本轮依据只有 R04，正文却写成“近期高校报道介绍历史照片、生活实物、文献资料”，并写“青少年时期居所”。

本次打开的 R04（梁溪区崇安寺街道，2025-04-28）写的是：秦邦宪故居位于无锡市梁溪区崇宁路112号；访问团看到的是其编译的书籍、使用过的皮箱等文物。同一篇里“大量实物、图片、文献”说的是无锡国专纪念馆，不是秦邦宪故居。这篇也没有“青少年时期居所”。

“历史照片、珍贵的生活实物与翔实的文献资料”和“青少年时期的居所”出现在江南大学 2026-04-23 的活动稿：https://slshe.jiangnan.edu.cn/info/1090/7283.htm 。这条在 06 里是 L-S09，没有进入 02 的 10 条来源索引。

应把 01 的展陈句改挂到这篇高校稿，并写明它是活动报道，不是馆方开放公告。不要让读者以为 R04 已经证明了这组展陈用词。

### 2. “2014年当年免费开放”把网页发布时间当成了开放年份

`06-既有资料参考/秦邦宪故居.md` 和 `地点结构化资料.json` 写“2014年高校介绍记当年免费开放”。

本次打开的无锡职业技术大学页面（https://www.wxit.edu.cn/info/1571/168001.htm ）发布日期是 2014-11-21，正文写的是 2005年5月9日免费开放。2014 不是免费开放的年份。

### 3. 张闻天专题页和无锡博物馆名录，02 与 06 对“有没有读到正文”说法相反

02 的 R09、R10 写本轮未取得正文。06 的 L-S05、L-S01 是同一网址，却写本轮已阅读正文。

本次打开后，两页都有正文，而且和档案里的这些字段一致：

- 无锡博物院《张闻天旧居》（页面时间 2016年12月07日）：汤巷45号；1975年8月25日从广东肇庆迁往无锡；周二至周日 9:00—17:00，16:00 后停止入场，周一闭馆（国家法定节假日除外）；电话 0510-82758567。
- 无锡博物馆名录（2025-07-25）：第21项陆定一祖居陈列馆，免费开放字段为“是”，地址为惠山区堰桥街道天一社区老陆巷4号；第24项张闻天旧居，免费开放字段为“是”，地址为汤巷45号。

这些字段可以保留，但必须改掉“未取得正文”。现在两套状态不能同时成立。名录里的“是”只说明 2025-07-25 那张表如此填写，不能当成 2026-10-11 仍在开放。

### 4. 腾讯地点查询有三套互相冲突的结果

同一天的三份记录对不上：

- `06-既有资料参考/腾讯地图候选点.json` 和 `腾讯点位测试结果.md`：陆定一祖居查询成功，地图地址是“陆巷4号”，坐标 31.642796, 120.293782；其余四处返回 121（每日调用量达到上限）。
- `03-入口与独立核对/入口补查与接口结果-第二轮.md`：本轮陆定一查询返回 121，上面这组坐标被写成上轮缓存。
- `06-既有资料参考/第二轮完善结果.md`：写成腾讯状态 112（来源 IP 未授权），并说候选 JSON 没有候选点。磁盘上的 JSON 有陆定一这条成功结果，不是空的失败记录。

游客入口没有被批准，这一点应保留。过程记录需要收成一套，否则无法判断这组坐标是哪一次查询返回的。地图返回电话 0510-83748119 只是平台字段，档案里不把它写成馆方电话是对的。名录“老陆巷4号”和地图“陆巷4号”仍应并列，不要合成同一个门牌写法。

### 5. 陆定一出生地已经不是“只见单页”，但仍不能定成出生地

`01-逐地点档案/陆定一祖居陈列馆.md` 写“出生地只见单页报道暂不采用”。

本次打开后，至少两页都写老陆巷是出生地：

- 共青团无锡市委网站 2018-08-07：位于堰桥街道天一社区老陆巷，“是陆定一同志出生地和和童年居住的地方”。这一页没有“4号”。
- 惠山区人民政府办公室 2024-02-28：同样写位于堰桥街道天一社区老陆巷，是出生地和童年居住的地方。入口补查只摘了巷名，没有记下这句出生地。这一页也没有“4号”。

两页用句非常接近，后一页像是沿用前一页，不能算两份独立证明，也不能再写“只见单页”。2012年无锡市人大建议写的是城中西河头28号（今县前街8号），并说那里是青少年时期居住、生活和读书的地方；它没有把县前街写成出生地。出生地仍应保持不定论，祖居也不能和县前街故居合并。
