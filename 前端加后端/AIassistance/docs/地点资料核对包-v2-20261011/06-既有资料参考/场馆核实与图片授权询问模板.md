# 场馆核实与图片授权询问模板（未发送）

您好，我们是无锡在校大学生，正在制作数字媒体竞赛作品“英迹·山河英雄谱”微信小程序。希望以有来源的资料介绍贵馆，并提供地点探索和参观提示。烦请确认以下信息：

1. 场馆正式名称、游客入口地址；是否有可公开的入口示意图或腾讯地图点位。
2. 当前开放时间、停止入馆时刻、闭馆日、预约方式及团队讲解要求；有无近期临时调整公告。
3. 可公开的咨询电话、收费和无障碍设施信息。

5. 贵馆是否持有所提供照片的许可权；如属于摄影者或其他权利人，能否提供相应联系渠道。
6. 希望采用的署名、版权声明、许可期限、地域、公开发布及商业用途限制。

拟用图片请逐张列出原始网址、图注和编号。未取得许可的照片暂不展示。我们不会把贵馆工作人员回复理解为未列明照片或全部馆藏资料的授权。

请记录回复人职务、回复日期、适用日期及可保存的书面依据，未经允许不公开私人联系电话和内部材料。现场核验需记下入口照片、GCJ-02坐标取得方式、采集日期与核验人；地图点位只是候选时请保留待核状态。

本模板未填写学校、联系人或作品发布期限，发出前由团队补齐；没有代表团队发出申请，也没有获得任何授权。
