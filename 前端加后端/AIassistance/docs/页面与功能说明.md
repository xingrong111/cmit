# 成员4页面与功能说明

## 01 AI阅读助手

顶部纸色山河装饰、朱红标题，入口明确分为“史料问答”和“操作导览”。快捷问题帮助首次使用；人物档案通过 `personId` 带入上下文，上方显示限定对象，可以取消限定。

用户问题与资料回答使用两种浅纸色卡片。一次最多500字，会话内存保留最近约20条；不写入服务端文件。结果卡可以查看原始出处、证据位置与转载说明；操作回答中的足迹入口可实际跳转，其他成员页面等待真实路径接入。

正在查阅时可以停止网络请求；连接失败可以重试。模型没有配置、异常、选取非法ID时回退到资料检索；没有直接相关资料显示“暂时不能确认”。不输出编造的历史对白。资料试读标识随服务端配置显示。

主要文件：`miniprogram/pages/assistant/index.*`、`server/src/assistant.js`。

## 02 历史足迹雷达

默认手动浏览无锡市，不会一进页面就索取定位。点击“使用当前位置”才进入隐私授权与位置调用。微信返回GCJ-02位置后查询附近已核入口；精度差于500米提示重试或选城。

允许城市、场馆类型、关键词筛选；附近半径可选3/10/30公里。城市浏览不填“距您多少米”。GPS模式只对有独立依据的入口算直线距离，并明确区别步行距离。不同意授权、定位失败、没有结果均有可继续使用的路径。

有实际坐标时用微信原生地图绘制标记，点击标记或气泡可打开详情。没有已核坐标时只显示山河雷达装饰，不制作假地图；GPS成功但没有可用场馆时显示没有附近已核入口，可手动选城。

主要文件：`miniprogram/pages/radar/index.*`、`miniprogram/utils/location.js`、`GET /api/places`。

## 03 历史地点详情

按“为什么了解—到了看什么—参观信息—关联人物—原始来源”组织。看点属于学习建议，不把建议描述成已经在馆内核到的展品。地址来自官方名录，不自动转成导航入口。

开放/预约信息必须有来源与最近核查日期，超过7天或未来日期不作为当前开放状态。没有依据显示“尚未核实”，不承诺无需预约、免费或正常营业。入口导航仅在入口坐标有独立依据时可用。

可以加入文化路线、向阅读助手提问。关联人物跳转交给主工程配置；空路径明确提示等待接入，不跳错人物。网络错误可重新加载。

主要文件：`miniprogram/pages/place/index.*`、`server/src/domain.js`。

## 04 文化路线

用户从地点加入最多4站，自行调整顺序并移除；本版不自动寻找所谓“最优路线”，不含现场任务、打卡证明、到达得分。路线选择保留在当前小程序内存，重启后不保证恢复。

选择当前起点后逐段调用腾讯步行规划，汇总真实平台距离与估算时间，绘制实际道路路径，列出分段指引。计算期间禁止改序和删除，避免显示旧站点结果。重复站点、缺入口坐标、单段直线跨度超过20公里、新近确认暂停开放的场馆、地图没有可达路线都有明确失败信息。

未核入口暂停规划；未配置地图服务不会返回假路线。地图预计时间不等于实际到达时间。导航按钮打开第一站地图位置，途中路径展示仍以服务响应为准。

主要文件：`miniprogram/pages/route/index.*`、`server/src/routes.js`。

## 05 来源页与隐私页

来源页保存完整原始URL与跳转最终URL，显示机构、发布日期、访问日期、短摘录、段落/章节位置和转载关系。点击复制原始网址便于核查，不用未配置业务域名的web-view强行打开外站。

隐私页说明位置目的、使用范围与外部地图服务。同意、拒绝和退出页面都完成授权回调；拒绝不影响城市浏览。不连续追踪位置，不做后台定位。

## 页面图的性质

`preview/images/01-AI阅读助手.png` 至 `04-文化路线.png` 为同一后端支持的浏览器审阅图。它们与微信页面使用同一配色和信息结构，但有适合浏览器的布局差异；真实微信系统导航、权限弹窗、地图视觉须以开发者工具和真机为准。
