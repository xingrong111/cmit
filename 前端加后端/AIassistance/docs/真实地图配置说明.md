# 真实地图与步行路线

旧浏览器版本为艺术示意图，并非真实街道地图。本轮接入腾讯JavaScript API GL加载代码，但尚未配置专用浏览器Key，不能称为真实底图已验证上线。

1. 腾讯位置服务应用中单独创建用于浏览器地图的Key。官方入门文档：https://lbs.qq.com/webApi/javascriptGL/glGuide/glBasic 。
2. server/.env已经添加空白TENCENT_MAP_BROWSER_KEY，请填写新Key，保留原TENCENT_MAP_KEY用于服务端WebService。不将模型Key或服务端Key发送给前端。
3. 重启Node服务，刷新预览。配置成功后足迹与路线页切换为可拖动、缩放的腾讯真实底图。失败时明确显示未加载，不宣称真实地图可用。
4. 浏览器Key会被浏览器加载，是前端公开配置，需按控制台可用的前端授权方式管理；不要复用服务端凭证。

地图中心只是城市浏览的画面范围，不是用户定位或游客入口。微信原生map已经支持城市底图，不依赖浏览器Key；未核验场馆不放置入口标记。浏览器不会直接拿WGS-84定位冒充GCJ-02；真实地图可点击选择路线起点。

实际路径走现有POST /api/routes接口，仅采用腾讯返回的道路路径。入口、额度、出口IP等条件不满足会明确报错；不能用示意连线绕过核验。原版图保留为清楚标注的顺序示意，并补上拖动。

55项后端测试及静态检查通过，39项浏览器离线回归通过（包含示意图拖动）。未实际验证浏览器腾讯底图：专用Key尚为空；未做微信真机检查。
