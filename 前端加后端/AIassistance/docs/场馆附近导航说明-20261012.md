# 场馆附近导航

按用户确认的范围完成网页与微信小程序修改，日期2026-10-12。

五馆现有腾讯点位显式批准用于venue_area附近导航；保留POI、查询时间、来源及比对说明。没有修改入口verified或开放状态，也没有把试读资料批准公开。正式publicMode下候选点依旧不放行。

接口新增routeReady、routeCoordinate、destinationKind、navigationNotice；navigationReady与entranceReady仍仅表示核验入口。附近筛选的直线距离到场馆地图点位，非步行距离。路线返回每段目标类型和来源，缓存包含目标类型，避免入口路线与附近路线混用。

网页可点击“导航至场馆附近”加入路线，点选起点后计算；也可“在腾讯地图查看附近”打开地图标点。此链接是地图位置展示，不代表已经开始逐步导航。小程序wx.openLocation使用routeCoordinate，可在微信地图页选择路线。用户位置只用于请求，不持久保存到服务端。

距离、耗时只展示实际接口返回结果；不含找入口、排队及预约等待。已知暂停开放时仍阻止路线，未知开放时明确提示需确认。
