# 成员4八项完善完成说明

日期：2026-10-11。微信原生小程序和本地浏览器预览同步更新；未合并成员模块，未做真机测试。

1. 助手首屏：缩短重复标题，压缩小迹欢迎卡，删除冗余介绍卡；保留三个场景、输入框与六项导航。开始对话后欢迎卡收起。
2. 回答组件：后端增加presentation，按已有响应数据决定chat/history/guide/places四类，保留原文段落、来源与允许操作；前端使用对应标题、气泡和地点卡。没有将模型输出作为HTML执行。
3. 足迹雷达：原生地图保持标记与选中卡联动；选中卡改为底部面板风格，地图高度统一。仅真实授权定位后显示用户位置，城市浏览不会自动显示定位标记。当前无核验入口时仍显示资料浏览，不提供假点位。
4. 背景与美术：增加原创江南水巷SVG装饰，雷达与地点使用地域场景；助手保持人物欢迎视觉，路线保持山河主题与轨迹轴。装饰不表示场馆实景复原，没有加入未经授权场馆照片。
5. 地点详情：故事卡、观看提示、到访信息和人物关联采用不同视觉层级；原始来源折叠。继续保留时期区分及开放、入口、照片许可状态。
6. 路线规划：助手新增城市、可用时间、步行偏好选择器，生成具体导览提问；路线已有预算、停留时间、排序和删点功能继续使用，增加可复制的路线计划。该计划不代表已经到访，也不估算未取得的步行时间。
7. 对话状态：等待提示改为小迹整理回答，保留停止与上下文；接口反馈模型不可用时支持手动重试，异常记录对应原提问，重试旧消息不会错用最新问题。禁止忙碌时重复提交，无自动循环重试。
8. 组件与动效：统一回答、证据、选中地点和路线计划的组件样式；去除全页卡片反复入场动画，保留新回复短淡入、小迹呼吸与思考标识；保留暂停动效及浏览器减少动态效果支持。没有增加语音模仿、现场任务或新的角色权限。
