# 缓存与独立导入演练 · 2026-10-11

## 已完成

- 步行路线：3分钟、最多100条内存缓存；相同有效请求合并为一个上游任务。
- POI候选：10分钟、最多50条内存缓存；相同城市与场馆名合并；错误不缓存。不会修改场馆资料或批准入口。
- 缓存返回cacheHit和coalesced；generatedAt保留真实生成时间。停服清空，不落盘定位。
- 一个订阅者取消只结束该订阅者；全部取消才中止上游。实际不同上游任务最多2个；缓存和合并不占新增任务。
- 本机开发工具POST /api/poi-candidates，仅接受当前资料中的placeId。PUBLIC_MODE=true或非回环请求拒绝。不是游客用的全网地点搜索。

## 本机候选查询

保持后端运行，在PowerShell执行：

```powershell
$poiBody = @{placeId='PLACE-WX-LDY'} | ConvertTo-Json
Invoke-RestMethod -Uri 'http://127.0.0.1:3100/api/poi-candidates' -Method Post -ContentType 'application/json' -Body $poiBody
```

首次查询会使用地图接口额度；请按需查询。多次相同请求在缓存期内复用，失败后不会假装成功。当前只编写测试模拟响应，没有消耗真实地图查询额度进行缓存测试。候选坐标不得直接启用导航。

## 独立导入、重启与回滚

运行：node scripts/rehearse-import.js

脚本在系统临时目录复制src、scripts、data和package.json，不复制.env。以独立端口3191运行，模型与地图Key为空。依次读取原资料、导入明确标为测试的摘要、启动新进程并HTTP核对、验证备份哈希、从备份导入回滚、再启动并HTTP核对。最后核对正式content.json哈希未改动。测试目录留存以便核对；没有将测试内容写到正式服务。
