# 隐私、配置与部署

## 数据流

用户明确点击定位后，微信获取当前GCJ-02坐标；附近检索把坐标传到本项目后端用于计算距离。生成路线时，后端将起点/已核站点坐标传给腾讯位置服务。历史模型请求只包含用户问题和候选史料，不包含定位坐标。

本版不保存聊天历史、用户位置或路线到数据库/磁盘；路线选择与位置只在当前小程序内存中使用。不做后台定位、连续轨迹、到达证明或现场任务。Node代码不记录请求正文、完整查询URL与密钥。

如果团队增加反向代理、云日志或网关，需要检查其默认访问日志。附近接口的GET URL包含坐标，不能让代理默认日志破坏“不记录位置”的约定。生产环境关闭该路径查询参数日志或做脱敏，并保证公开隐私保护指引与真实处理一致。

## 平台配置

原生位置接口的声明、公众平台接口权限、用户隐私同意、设备位置授权是不同层面，不能只改app.json就保证成功。账号类别和权限申请结果以微信公众平台实际后台为准。参考[微信位置接口](https://developers.weixin.qq.com/miniprogram/dev/api/location/wx.getLocation.html)、[隐私授权开发指引](https://developers.weixin.qq.com/miniprogram/dev/framework/user-privacy/PrivacyAuthorize.html)。

开发者工具允许本地HTTP不代表真机和发布允许。正式接口使用可达HTTPS域名，配置request合法域名；如未来使用web-view打开外站，还需要业务域名条件，本版未依赖web-view。

当前使用基础库具有隐私API时展示自定义授权页；调用不支持的环境走位置接口自身授权流程。真机仍须测试拒绝、退出隐私页、后续设置授权、弱定位、断网和地图渲染。模拟测试不替代平台审核。

## 配置项

| 配置 | 用途 |
|---|---|
| HOST / PORT | 默认127.0.0.1:3100，只本机访问；部署时按团队服务方式配置 |
| PUBLIC_MODE | false允许资料试读；true仅verified且published的条目，并关闭辅助预览 |
| MODEL_BASE_URL / MODEL_NAME | 默认智谱GLM对话接口及glm-4.7-flash；兼容服务需要实测JSON格式及thinking参数 |
| MODEL_API_KEY | 只由Node服务端读取；无密钥降级检索 |
| TENCENT_MAP_KEY | 腾讯位置WebService步行调用，只由服务端使用 |
| miniprogram/config.js apiBase | 小程序访问后端的公开地址，不填任何服务密钥 |

`.env`不入仓库、不入交付压缩包。共享接口文档不能贴真实密钥。服务端仅返回是否配置的布尔值。

地图和模型是外部计费服务，当前不预估过时价格。调用额度、账户权限、服务端IP限制/签名要求以自己的服务账户当前设置为准。若启用了签名校验，本版仅key参数的适配需补签名后再联调，不能宣称全部密钥配置都通用。

## 服务的实际边界

后端为一个进程的只读模块服务，使用内存IP限流，不是完整的生产账号系统。没有写入接口，因此没有公开审核发布权限；登录与管理员管理继续使用团队主工程。主网关是否强制登录、如何验证会话，以团队统一策略接入。

部署可使用进程管理器和HTTPS反向代理。重启后JSON重新读取、限流状态清空；多个实例需共享限流与统一内容仓库。请求体上限12KB、问句上限500字、模型15秒超时、每段地图12秒超时。多站路线按序调用，最多4段，客户端总请求超时55秒。

服务器不配置浏览器跨域通配CORS；同源预览正常，小程序网络请求无需借助浏览器CORS。API根路径与团队现有接口冲突时需要统一路由规划。

## 地图IP白名单联调（2026-10-11）

实际腾讯请求先走IPv6，和用户填写的IPv4不同。npm start已增加--dns-result-order=ipv4first。使用IPv4时，腾讯返回112并报告出口153.35.189.130，与第三方查询所得153.35.189.2不同。请将腾讯实际报告的出口IP加入白名单，保留确实使用的其他出口；校园网可能有多出口，单次查询不能保证固定。当前尚无成功步行响应，测试坐标没有保存成历史场馆入口。账户免费配额、超额规则以登录控制台显示为准，未购买任何套餐。
