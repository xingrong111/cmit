# 足迹与路线主题地图

本轮为历史足迹雷达及文化路线增加原创SVG地图意象：宣纸底色、江南水系、街巷轮廓、园林色块、朱红编号标记与指南针。复用项目配色，不复制获奖作品地图。

足迹示意图点选标记可选中对应真实资料条目；支持1—1.6倍缩放与复位。路线示意图最多4站，编号、地点名称和连线按当前加入顺序更新，点选打开详情。

示意图街道、水系与标记位置是艺术排布，不是无锡或常州真实街道及入口点位，也不展示比例尺或假距离。页面明确标注“城市意象”“顺序示意”和非真实路径说明。

微信端有真实定位或已核坐标时仍显示原生map，实际步行路线仍由腾讯接口计算；未取得真实路线时显示顺序示意图。浏览器使用可操作示意图，不调用伪造GPS。

验证：55项后端回归、38项浏览器检查及静态检查通过。新增检查覆盖地图地点标记、缩放生效、路线顺序及示意说明。未进行微信真机测试。后续入口核验完成可直接沿用既有真实地图及路径接口。
