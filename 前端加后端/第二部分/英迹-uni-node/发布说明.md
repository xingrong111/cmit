# 发布与接入

微信小程序源码已经按uni-app路线组织，构建通过与实际发布是两个阶段。正式发布需要账号持有人提供小程序AppID（可自行填写）、配置合法HTTPS请求域名、在微信开发者工具完成真机检查，并在微信公众平台完成所需资料和审核。

无需向聊天发送AppSecret。当前不请求手机号、定位、相机等权限。原资料图片许可未核齐，采用原创山水意象。

后端为Node.js 24/Express/SQLite，只读资料接口；SQLite路径必须在部署主机的持久目录中。没有账号、云主机或域名时可以完成本地工程与小程序编译产物，不能声称正式上线。

H5可以用同一前端编译。一种部署连接Node.js正式HTTPS接口；另一种用于静态展示，导出原API公开结果，在浏览器内进行只读筛选，明确不代替生产Node.js后端。

本机书签与记录不会同步到其他设备；后续统一账户服务接入时需迁移独立身份与用户数据接口。
