# B版全站视觉统一

首页、人物、长卷、足迹、小迹、学习、我的及应用外壳中的相关子页面均默认采用B版。以本次从 `xingrong111/cmit` 拉取的 `5691586` 为功能基线。

## 设计

- 暖白宣纸、墨绿标题、朱红操作和浅金边线。
- 页面背景随文档滚动，不遮挡点击，不降低地图、人物照片、图谱和文字的不透明度。
- 我的保留原有青绿山水背景，小迹和长卷采用同一版本；其他页面使用首页山河背景。桌面端两组背景不透明度分别为9%与10%，移动端均为8%，背景随页面滚动。
- 标题统一宋体字体栈，正文、输入和操作使用清晰的黑体字体栈。系统安装的字体决定实际回退字体，无需在线字体服务。
- 原有标准/大字号设置优先于主题字号；答题选中、正确与错误状态保留原有颜色反馈。
- 地图、聊天、题目及主要内容卡片保持清晰纸白底色。

## 功能保护

本轮仅增加CSS、外观属性初始化和HTML样式资源引用。所有原有Vue脚本、业务JS/MJS、配置JSON和数据文件按换行规范化后与基线一致。核对覆盖178个原文件或脚本段，功能差异为0。新增外观脚本只设置文档外观属性，不读写用户业务状态。

原地图组件、人物筛选、学习关卡、路线编排、账户权限和阅读记录逻辑未改。主导航的七个页面、原有学习入口和返回入口保留。

## 验证

网页与微信小程序编译通过；小程序提示部分HTML标签选择器不适用，原有功能脚本未改，未进行微信真机视觉验证。全站B版主要通过浏览器预览验收。

浏览器核对了七个主页面、人物学习入口、地图/城市/路线入口、聊天输入、五组学习关卡以及个人中心字号切换。大字号测试后已恢复原标准字号设置。178项原文件/脚本一致性报告附在修改包中。

Sites端仅同步构建资源和HTML外观资源引用，保留现有云端账户适配及数据。修改提交到独立视觉分支；未合并主分支、未发布线上。
