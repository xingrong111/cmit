# 山河有迹 v3.0

面向广大群众的红色文化探索网页应用，将人物阅读、互动故事、文化寻访、智能导览和学习回顾连接起来。

当前代码入口为 **`v2/`**。目录名沿用原工程名称，发布版本以 `v2/VERSION`、版本分支及同名标签为准。

- 在线体验：https://1.92.99.71:8443/
- 本版本：`v3.0`（2026-10-23）
- 更新说明：[v3.0 更新说明](v2/docs/v3.0更新说明.md)

## 核心功能

- 全国地域及人物索引、人物档案、时间长卷、关系图谱与资料来源。
- 江姐主题全景互动故事、剧情选择、角色配音、进度保存与回看。
- 文化场馆与路线编排；步行、驾车、公交、骑行切换；逐站预计到达及行程结束时间。
- 小迹智能导览、人物和场馆相关问答与继续阅读入口。
- 账户、邮箱验证码、评论审核、学习挑战、成长称号及数字文创。

## 本机运行

需要 Node.js 24 或更新版本及 npm。邮箱发送功能另需 Python 3 和实际 SMTP 配置。

在仓库根目录依次执行：

```sh
cd v2/frontend
npm ci
npm run build:h5
cd ../services/reading
npm ci
cd ../..
node 启动服务.mjs
```

打开 http://127.0.0.1:3210/ 。启动器同时启动 3211—3215 的五个后端模块；终止启动器可关闭本次启动的服务。

主运行入口读取 `frontend/dist/build/h5`。该构建目录不入库，首次启动必须先构建；`网页端/页面` 保存了本次交付的页面副本。

### 地图、模型与邮件配置

将 `v2/services/guide/server/.env.example` 复制为同目录 `.env`，填写自己的地图与模型服务配置。启动器会读取此导览配置。

如需启用邮件验证码，将 `v2/services/account/account.env.example` 复制为同目录 `account.env` 并填写 SMTP 参数，然后在 `v2` 目录使用：

```sh
node --env-file=services/account/account.env 启动服务.mjs
```

地图浏览器 Key 与服务端 WebService Key 的用途不同，分别按服务商要求设置域名、配额与权限。浏览器 Key 会用于地图展示；模型及服务端密钥仅配置在后端。生产服务配置和真实用户数据不包含在仓库中。
