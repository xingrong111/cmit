# 山河有迹

革命历史文化探索项目，包含全国地图与人物检索、深度人物档案及关系图谱、账户评论审核、AI导览与文化足迹、学习挑战，以及江姐主题全景示例。

在线网页：https://shanhe-youji-20261017.bushystar3.chatgpt.site

## 目录

| 目录 | 内容 |
| --- | --- |
| `V1/frontend` | 当前合并版uni-app源码，支持网页及微信小程序构建 |
| `V1/services/reading` | 人物、史料、时间线、关系图谱阅读接口 |
| `V1/services/account` | 本机账户、评论与管理员审核服务 |
| `V1/services/guide` | 小迹AI导览、历史足迹雷达和文化路线 |
| `V1/services/学习` | 五组150题学习挑战与资料导入代码 |
| `V1/微信开发者工具导入包` | 当前已组装的小程序导入文件 |
| `V1/江姐VR示例` | 独立360度全景交互示例及素材 |
| `V1/tools` | 资料合并、构建、组装及检查脚本 |
| `Sites发布版` | 当前线上站点源工程；云端身份、D1存储和API适配 |
| `前端加后端` | 各成员独立交付的原始代码，供追溯参考 |

日常修改优先使用V1；各成员原始代码不等同于最新整合版本。

## 本机运行V1

需要Node.js 24及兼容的Python环境。分别在 `V1/frontend` 和 `V1/services/reading` 安装锁文件对应依赖；已有锁文件时使用 `npm ci`。

将 `V1/services/guide/server/.env.example` 复制为 `.env`，在本机填写模型和腾讯地图配置。不要把密钥放在前端。

在V1目录运行：

```sh
node 启动服务.mjs
```

打开 http://127.0.0.1:3110/ 。网页构建产物未提交，首次运行前需要构建前端：在 `V1/frontend` 使用项目package.json定义的构建脚本（`npm run build:h5`），或使用V1/tools中的合并构建脚本。部分自动化脚本按原Windows开发环境配置，换电脑时须调整本机运行时路径。

账户服务启动时会创建本机演示数据；演示账户不得直接用于公开生产环境。

## 微信小程序

可导入 `V1/微信开发者工具导入包` 预览当前组装版本。真机运行仍须配置自己的AppID、可达的HTTPS后端、合法域名和地图服务授权。后续代码修改需重新构建并组装，不能只改导入包。

## Sites线上版本

`Sites发布版` 使用Sites提供的ChatGPT身份验证及D1持久化。它与本机演示账户、个人学习记录分别保存。运行时密钥在Sites中配置，仓库不包含密钥；复制仓库不会自动取得生产站点权限或生产数据。

在线内容修改后需通过Sites重新构建发布，推送GitHub本身不触发该站点自动部署。

## 资料与素材边界

人物资料、地图人数和题库保留原有审核状态；收录人数不代表全国历史总人数。图片、字体、第三方库的来源和许可说明以各模块现有记录为准，本仓库未对全部内容统一授予开源许可。

江姐全景为文学主题艺术化示例，不是历史现场复原，也不是可自由行走的三维建筑模型。
